# 选题 Agent 模板包

第一件工具（11/14–15 搭，11/15 launch）。读者拿来就能用，不用克隆仓库、不用装任何东西；仓库在底下，交付的是能直接用的东西。

## 包里有什么

- `templates.md` — 7 个选题模板，一周每天一个，每个模板带 9 个固定栏（见下）。
- `prompts/topic-prompt.md` — 选题提示词：给赛道 + 关键词，出这周的选题。
- `sop.md` — 一周选题工作流：从挖需求到发笔记到 24h verdict。
- `topic_agent.py` — 小 CLI：输入赛道/关键词，输出一周选题带钩子（模板驱动，无需 API key，离线能跑）。

## 固定栏（每个模板都有这 9 栏，缺一栏就不算写完）

1. 选题 — 一句话，这条讲什么
2. 给谁 — 具体人群，不是"所有人"
3. 痛点 — 读者卡在哪，具体场景
4. 钩子 — 标题 + 封面第一句（标题 ≤20 字，讲读者利益）
5. 结构 — 开头 → 真经历 → 做法 → 新发现
6. 证据 — 要哪种实测数 / 真实案例（没证据就不写数字）
7. 忌 — 这条最容易写成什么烂样子
8. 下一步 — 读者看完立刻能干什么
9. 回看场景 — 读者下次什么时候会翻出来（2026-11-14 DISCOVERY 新增：结尾不写"记得收藏"，写清回看场景）

## 标题自测（2026-11-14 DISCOVERY 新增）

把标题念给一个不认识你的人，他能不能说出"我什么时候会用到这条"。说不出来，标题没过关——不是标题不够响，是没讲清使用场景。
